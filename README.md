# K-Bit Calc

A Kotlin-based command-line utility for arbitrary-precision bitwise operations.

## Usage
Run the application and enter commands:
- `AND <val1> <val2>`
- `OR <val1> <val2>`
- `XOR <val1> <val2>`
- `XORN <val1> <val2>` (XOR with mask)
- `XNOR <val1> <val2>`
- `NAND <val1> <val2>`
- `NOR <val1> <val2>`
- `NOT <val>`
- `LSH <val> <bits>` (Left Shift)
- `RSH <val> <bits>` (Right Shift)
- `EXIT`

Supports formats: Decimal, Hex (`0x...`), and Binary (`0b...`).
